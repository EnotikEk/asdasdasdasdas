# Photo Retouch Pro — Flask

Веб-редактор фотографий. Запуск из корня репозитория:

```sh
docker compose up -d --build
```

Открыть http://localhost:5000. Проверка: `docker compose ps`, логи: `docker compose logs`, остановка: `docker compose down`.

Фотографии, ресурсы и сохранённый веб-проект находятся в `photo_retouch_app/PhotoRetouchProject`, подключённой к `/data` контейнера. Данные сохраняются после пересоздания контейнера. Существующие фотографии доступны в библиотеке. Старые `.proj` можно открыть кнопкой «Открыть .proj»; ресурсы должны присутствовать в папках проекта. Сохранение на сервере использует один общий `web-project.proj`; отдельные проекты можно скачивать как JSON.

Возможности: загрузка фотографий, фонов, прозрачных рамок и костюмов, шрифтов; шесть коррекций; текст с координатами и цветом; масштаб, поворот и прозрачность костюма; видимость и порядок слоёв; отмена и повтор; поворот, отражение и обрезка фото; экспорт PNG/JPEG/TIFF. Трансформации создают новые файлы, не меняя исходник. Увеличение ×2 использует Lanczos. Кнопка «Чёрно-белое» обесцвечивает фотографию с сохранением прозрачности. Кнопка «Удалить фон» использует локальную модель rembg/u2netp; веса включаются в Docker-образ при сборке. Обе операции поддерживают отмену. Обрезка задаётся координатами в пикселях исходной активной фотографии.

Интерфейс предназначен для локальной работы: порт опубликован только на 127.0.0.1. Загрузка ограничена 40 МБ и 32 Мп. Для увеличения ×2 — максимум 8 Мп.

Локальный запуск без Docker (Python 3.10+):

```sh
cd photo_retouch_app
pip install -e .
python -m photo_retouch
```

Проверка HTTP/API внутри работающего контейнера:

```sh
docker compose exec -T photo-retouch python -m unittest discover -s /app/tests -v
```

Тесты в `photo_retouch_app/tests/test_web.py`; Docker образ копирует их в `/app/tests`. Старый PyQt-интерфейс сохранён в `gui/` для справки, веб-версия от него не зависит.
